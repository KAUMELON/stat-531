25  Mixed models and variance components

Learning outcomes

Distinguish fixed and random effects, estimate variance components by the ANOVA method and by REML, compute heritability, GCV and PCV, analyse multi-environment trials and split plots as mixed models, and test contrasts in mixed models.

25.1 Fixed and random effects

A factor in a model is treated as

  • fixed when its levels are chosen deliberately and conclusions apply only to those levels: fertiliser doses, irrigation schedules, a set of released varieties being compared;
  • random when its levels are a random sample from a larger population, and interest lies in the variability of that population: blocks, years, locations, animals, or genotypes sampled from a breeding population.

A model containing both is a mixed model. For a random factor we estimate a variance component, not the effect of each level. Variance components are central in plant breeding (genetic variance, heritability), in sampling (variation between and within plots) and in multi-location trials (genotype × environment variance).

Mixed models also handle designs with several error terms (split plots, repeated measures) and unbalanced data in a unified way.

Note

In R, mixed models are fitted with lmer() from the lme4 package (Bates et al. 2015). The lmerTest package adds F tests with Satterthwaite or Kenward–Roger degrees of freedom. Random effects are written as (1 | factor): “a random intercept for each level of factor”.

25.2 Estimating variance components by the ANOVA method

For a one-way random model \(y_{ij} = \mu + g_i + e_{ij}\) with \(g_i \sim N(0, \sigma_g^2)\) and \(e_{ij} \sim N(0, \sigma_e^2)\), the expected mean squares are

Source df MS E(MS)
Genotypes \(g - 1\) \(M_g\) \(\sigma_e^2 + r\sigma_g^2\)
Error \((g-1)(r-1)\) \(M_e\) \(\sigma_e^2\)

(the same holds in an RCBD, with blocks removed). Equating mean squares to their expectations gives

\[\hat\sigma_e^2 = M_e, \qquad \hat\sigma_g^2 = \frac{M_g - M_e}{r}\]

25.2.1 Example 25.1: genetic parameters in a potato trial

We return to the 28 potato genotypes in an RCBD with three replications at La Molina (plrv, Chapter 22). If these genotypes are regarded as a sample from a breeding population, the genotypic variance and heritability describe how much of the variation in yield is genetic.

library(agricolae)
data(plrv)
plrv$Rep <- factor(plrv$Rep)
lm02 <- droplevels(subset(plrv, Locality == "LM-02"))

tab <- summary(aov(Yield ~ Rep + Genotype, data = lm02))[[1]]
tab
            Df Sum Sq Mean Sq F value      Pr(>F)    
Rep          2    480   240.1    8.97     0.00043 ***
Genotype    27   3890   144.1    5.38 0.000000077 ***
Residuals   54   1445    26.8                        
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
r  <- 3
Mg <- tab[2, "Mean Sq"]
Me <- tab[3, "Mean Sq"]
sigma2_g <- (Mg - Me) / r          # genotypic variance
sigma2_e <- Me                     # error (environmental) variance
sigma2_p <- sigma2_g + sigma2_e    # phenotypic variance
xbar <- mean(lm02$Yield)

c(sigma2_g = sigma2_g, sigma2_e = sigma2_e, sigma2_p = sigma2_p,
  H2_plot  = sigma2_g / sigma2_p,                    # broad-sense heritability, plot basis
  H2_mean  = sigma2_g / (sigma2_g + sigma2_e / r),   # heritability, entry-mean basis
  GCV = sqrt(sigma2_g) / xbar * 100,                 # genotypic coefficient of variation
  PCV = sqrt(sigma2_p) / xbar * 100)                 # phenotypic coefficient of variation
sigma2_g sigma2_e sigma2_p  H2_plot  H2_mean      GCV      PCV 
 39.1015  26.7559  65.8574   0.5937   0.8143  18.0493  23.4243

Broad-sense heritability on a plot basis is 0.59, and on an entry-mean basis (relevant when selection is based on genotype means over three replications) it is 0.81. The genotypic coefficient of variation (18%) is a large part of the phenotypic coefficient of variation (23.4%), indicating considerable genetic variability for yield.

Warning

The likelihood-ratio test for a variance component tests a parameter on the boundary of its space (\(\sigma_g^2 = 0\)), so the reported p-value is conservative; halving it gives a closer approximation.

25.4 Multi-environment trials

The full plrv data include the 28 genotypes in six environments. A mixed model separates the genotypic variance from the genotype × environment (G × E) interaction variance. Environments are treated as fixed here, and replications are nested within environments:

m2 <- lmer(Yield ~ Locality + (1 | Locality:Rep) + (1 | Genotype) +
             (1 | Genotype:Locality), data = plrv)

Heritability on an entry-mean basis across \(e\) environments and \(r\) replications is

\[H^2 = \frac{\sigma_g^2}{\sigma_g^2 + \sigma_{ge}^2/e + \sigma_e^2/(re)}\]

s2g  <- vc2$vcov[vc2$grp == "Genotype"]
s2ge <- vc2$vcov[vc2$grp == "Genotype:Locality"]
s2e  <- vc2$vcov[vc2$grp == "Residual"]
e <- 6; r <- 3
s2g / (s2g + s2ge / e + s2e / (r * e))
[1] 0.729

25.4.1 BLUPs: predicting genotype values

When genotypes are random, their predicted effects are best linear unbiased predictions (BLUPs). BLUPs shrink the observed genotype means towards the overall mean, more so when the heritability is low, and they are widely used to rank genotypes in breeding programmes.

blup <- ranef(m2)$Genotype
blup$Genotype <- rownames(blup)
names(blup)[1] <- "BLUP"
head(blup[order(-blup$BLUP), ], 6)
        BLUP Genotype
141.28 6.624   141.28
Unica  6.148    Unica
319.20 5.896   319.20
235.6  5.806    235.6
157.26 4.579   157.26
450.3  4.029    450.3

The genotype Unica (a released variety) has the highest predicted genetic value for yield across environments.

25.5 Split-plot designs as mixed models

A split-plot design has two error terms because main plots and sub-plots are units of different sizes. In a mixed model, both are represented by random effects: blocks and main plots (variety within block) are random. For the oats experiment (Chapter 22):

25.6 Testing the significance of contrasts in mixed models

Contrasts (Chapter 23) are tested in mixed models with emmeans::contrast(), which uses the appropriate standard error and degrees of freedom. For the four equally spaced nitrogen levels, orthogonal polynomial contrasts are obtained with method = "poly":

contrast(emm_N, method = "poly")
 contrast  estimate    SE df t.ratio p.value
 linear       147.3 14.00 45  10.503 <0.0001
 quadratic    -10.3  6.27 45  -1.647  0.1065
 cubic         -2.0 14.00 45  -0.143  0.8873

Results are averaged over the levels of: V 
Degrees-of-freedom method: kenward-roger

The linear trend is highly significant, while the quadratic and cubic components are not, confirming the conclusion of Chapter 23. Custom contrasts are specified as a list of coefficients, for example nitrogen applied (any level) versus no nitrogen:

contrast(emm_N, list("N applied vs none" = c(-3, 1, 1, 1) / 3))
 contrast          estimate   SE df t.ratio p.value
 N applied vs none     32.8 3.62 45   9.050 <0.0001

Results are averaged over the levels of: V 
Degrees-of-freedom method: kenward-roger

Applying nitrogen increased yield by 32.8 units on average over the three levels.

25.7 Live R laboratory

Variance components and heritability

Edit the code, then select Run R. The first run downloads R into your browser and may take a little time. Copy code lets you use the example in RStudio.

# Six potato genotypes in an RCBD with three replications (La Molina)
genotype <- factor(rep(c("102.18", "104.22", "121.31", "141.28", "157.26", "163.9"), each = 3))
rep_ <- factor(rep(1:3, times = 6))
yield <- c(36.5, 29.6, 30, 36.5, 40.2, 40.9, 39.3, 32.2, 43.7,
           35.6, 44.8, 21.5, 43.3, 46.3, 45.9, 36.7, 33.7, 16.3)
tab <- summary(aov(yield ~ rep_ + genotype))[[1]]
tab
Mg <- tab[2, "Mean Sq"]; Me <- tab[3, "Mean Sq"]; r <- 3
s2g <- max((Mg - Me) / r, 0); s2e <- Me
c(sigma2_g = s2g, sigma2_e = s2e, H2_mean = s2g / (s2g + s2e / r),
  GCV = sqrt(s2g) / mean(yield) * 100, PCV = sqrt(s2g + s2e) / mean(yield) * 100)

Investigate. If \(M_g\) were smaller than \(M_e\), the ANOVA estimate of \(\sigma_g^2\) would be negative. What does the code do in that case, and how does REML avoid the problem?

Important formulae

Variance components by the ANOVA method:

\[ \hat\sigma_e^2 = M_e, \qquad \hat\sigma_g^2 = \frac{M_g - M_e}{r} \tag{25.1}\]

Broad-sense heritability (plot and entry-mean basis):

\[ H^2 = \frac{\sigma_g^2}{\sigma_g^2 + \sigma_e^2}, \qquad H^2_{\bar y} = \frac{\sigma_g^2}{\sigma_g^2 + \sigma_e^2/r} \tag{25.2}\]

Genotypic and phenotypic coefficients of variation:

\[ \text{GCV} = \frac{\sigma_g}{\bar y}\times100, \qquad \text{PCV} = \frac{\sigma_p}{\bar y}\times100 \tag{25.3}\]

Quick revision

  • Chosen levels → fixed; sampled levels → random.
  • ANOVA method → simple, can be negative; REML → preferred.
  • Heritability, GCV, PCV → genetic variability for selection.
  • Multi-environment trials → separate \(\sigma_g^2\) and \(\sigma_{ge}^2\).
  • Split plots, missing data, unbalanced designs → mixed models with lmer() and emmeans.
