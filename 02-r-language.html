2  Objects, data structures, and functions

2.1 Learning outcomes

Create and subset vectors, matrices, data frames, and lists; recognize numeric, character, logical, and factor variables; and write a small reusable function.

In this section we will be dealing with basic operations using R. One should be aware of these basics before proceeding to any kind of data analysis using R.

The RStudio interface is simple. You type R code into the bottom line of the RStudio console pane (see figure Figure 1.3) and then click Enter to run it. The code you type is called a command, because it will command your computer to do something for you. The line you type it into is called the command line.

‘#’ hashtag in R
R treats the hashtag character, ’#’in a special way; R will not run anything that follows a hashtag on a line. This makes hashtags very useful for adding comments and annotations to your code. We will be able to read the comments, but your computer will not process it.

2.5.3 Data frames

A data frame is the data type, we will be going to use frequently. A data frame is like a matrix but can have columns with different types (numeric, character, logical). Rows are observations (individuals) and columns are variables. Function data.frame() is used to create data frame

friends_data <- data.frame(
  name = c("asha", "adhi", "aravind", 
                  "mary"), 
  age = c(20,23,22,21),
  height = c(180, 170, 185, 169),
  married = c(TRUE, FALSE, TRUE, TRUE)  
)  

# Print
friends_data
     name age height married
1    asha  20    180    TRUE
2    adhi  23    170   FALSE
3 aravind  22    185    TRUE
4    mary  21    169    TRUE

To check whether a data is a data frame, use the is.data.frame() function. Returns TRUE if the data is a data frame:

is.data.frame(friends_data)

To check whether a data is a matrix, data frame or any other class use the function class()

2.6 Agricultural applications, interpretation, and further practice

2.6.1 Values and vectors

An atomic vector holds values of one underlying type. Combining numbers and text causes coercion, usually to character. Numeric values support arithmetic; character values describe names; logical values represent TRUE or FALSE. A factor records categories with a specified set of levels.

yield <- c(4.2, 4.8, 5.1, 4.5)
variety <- c("A", "A", "B", "B")
irrigated <- c(TRUE, TRUE, FALSE, FALSE)
class(yield)
[1] "numeric"
yield[2]
[1] 4.8
yield[c(1, 3)]
[1] 4.2 5.1
yield[yield > 4.5]
[1] 4.8 5.1
yield * 1000                    # t/ha to kg/ha
[1] 4200 4800 5100 4500
factor(variety, levels = c("A", "B"))
[1] A A B B
Levels: A B

R indexes from 1. Square brackets select elements. > compares values; == tests equality; != tests inequality; and %in% tests membership. Use & and | for elementwise “and” and “or”. Arithmetic is vectorized. R can recycle a shorter vector, so check lengths when combining measurements; recycling does not establish which observations belong together.

plot_id <- 1:4
plot_id[plot_id %in% c(2, 4)]
[1] 2 4
yield[yield >= 4.5 & variety == "B"]
[1] 5.1 4.5
length(yield)
[1] 4

2.6.4 Lists, missing values, and functions

A list can contain objects of different structures. Statistical model results are often lists. $ or [[ ]] extracts a component, while [ ] keeps a sublist.

trial <- list(site = "Teaching farm", observations = field,
              units = "t/ha")
trial$site
[1] "Teaching farm"
trial[["observations"]]
  plot_id variety yield_t_ha irrigated yield_kg_ha
1       1       A        4.2      TRUE        4200
2       2       A        4.8      TRUE        4800
3       3       B        5.1     FALSE        5100
4       4       B        4.5     FALSE        4500
x <- c(4.2, NA, 5.1)
is.na(x)
[1] FALSE  TRUE FALSE
mean(x)
[1] NA
mean(x, na.rm = TRUE)
[1] 4.65

NA records an unknown value. It is neither zero nor the character string "NA". Use is.na(x), not x == NA. NaN is an undefined numeric result and Inf represents infinity. Removing missing values from a calculation changes its denominator and may change the population represented by the result.

A function names a repeatable calculation. Arguments supply inputs and the final expression supplies the return value.

to_t_ha <- function(mass_kg, area_m2) {
  stopifnot(is.numeric(mass_kg), all(is.finite(mass_kg)),
            all(mass_kg >= 0), is.numeric(area_m2),
            length(area_m2) == 1, is.finite(area_m2), area_m2 > 0)
  mass_kg / area_m2 * 10
}
to_t_ha(c(9.6, 11.2), 20)
[1] 4.8 5.6

The checks stop the calculation for invalid inputs. Later, the pipe |> passes a result into the first argument of the next function: sqrt(16) and 16 |> sqrt() are equivalent. A pipe expresses a sequence, not a new statistical method.

Important formulae

Number of elements in an arithmetic sequence from \(a\) to \(b\) in steps of \(h\):

\[ n = \frac{b-a}{h} + 1 \tag{2.1}\]

Position of element \((i, j)\) in a matrix with \(n_r\) rows filled by column:

\[ k = (j-1)\,n_r + i \tag{2.2}\]

Quick revision

  • Objects are created with <-; R is case sensitive.
  • Vector → one type; matrix → one type in two dimensions; data frame → columns of different types; list → anything.
  • Mixed types → coerced to the most general type (logical → numeric → character).
  • NA → missing; most summaries need na.rm = TRUE.
  • Treatments, blocks and varieties → factors.
