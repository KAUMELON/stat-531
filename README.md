# Data Analysis Using Statistical Packages (STAT 531)

A complete guide to data analysis in agricultural research using R, written for the STAT 531 course of the Post Graduate programme, Kerala Agricultural University.

**Read online:** https://kaumelon.github.io/stat-531/

Author: Dr. Pratheesh P. Gopinath, Department of Agricultural Statistics, College of Agriculture, Vellayani, Kerala Agricultural University.

## Building the book

The book is written in R Markdown with [bookdown](https://bookdown.org). Install the packages listed in the Preface, then run

```r
source("_build.R")
```

The rendered website is written to `docs/`, which GitHub Pages serves. `_deploy.sh` rebuilds and pushes in one step.
