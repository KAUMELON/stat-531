14  Correlation and regression for agricultural prediction

14.1 Learning outcomes

Distinguish Pearson and Spearman correlation, interpret simple and multiple regression coefficients, check model assumptions and influential observations, and evaluate prediction on held-out observations.

14.2 Association is not a treatment effect

Pearson’s correlation measures the strength and direction of a linear relationship between quantitative variables. Spearman’s correlation applies Pearson’s idea to ranks and describes monotonic association. Neither establishes causation, and a value near zero need not imply the absence of a nonlinear relationship. Both can be distorted by pooling unlike groups or by dependence among observations.

The simulated farm_yield.csv contains 100 independent teaching records with nitrogen application, seasonal rainfall, and yield. It is constructed for a regression lesson and is not evidence for a real fertilizer recommendation.

farm <- read.csv("data/farm_yield.csv")
plot(yield_t_ha ~ nitrogen_kg_ha, farm, pch = 19,
     xlab = "Nitrogen (kg/ha)", ylab = "Yield (t/ha)")
cor.test(farm$nitrogen_kg_ha, farm$yield_t_ha, method = "pearson")

Inspect scatter plots before interpreting a correlation coefficient. Pearson’s usual test assumes independent pairs and a suitable bivariate sampling model; ranks do not fix clustering or confounding. Spearman’s test uses an approximation here because rounded measurements can create ties.

14.3 Simple linear regression

The model \(Y_i=\beta_0+\beta_1X_i+\epsilon_i\) describes a conditional mean response. The intercept is the predicted mean when \(X=0\); the slope is a change in mean response per unit increase in \(X\). Least squares minimizes squared residuals. The regression direction matters: a model predicting yield from nitrogen is not interchangeable with one predicting nitrogen from yield.

simple <- lm(yield_t_ha ~ nitrogen_kg_ha, data = farm)
summary(simple)

The slope has units t/ha of yield per kg/ha of applied nitrogen. Its estimate is an association in these data, conditional on the specified model. If zero nitrogen lies outside the observed range, the intercept is an extrapolation and need not have a useful agronomic interpretation.

14.4 Worked calculation: what least squares estimates

For a simple regression with an intercept, the estimated slope is

\[b_1=\frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2},\qquad b_0=\bar{y}-b_1\bar{x}.\]

The slope is undefined when every predictor value is identical: the denominator is zero. A range of predictor values is necessary to estimate a relationship. The calculation below verifies the coefficients from lm() rather than treating its output as a black box.

x <- farm$nitrogen_kg_ha
y <- farm$yield_t_ha
b1 <- sum((x - mean(x)) * (y - mean(y))) / sum((x - mean(x))^2)
b0 <- mean(y) - b1 * mean(x)
rbind(manual = c(intercept = b0, slope = b1), lm = unname(coef(simple)))
       intercept      slope
manual  3.077606 0.01831709
lm      3.077606 0.01831709

Residuals are observed minus fitted responses. With an intercept, least squares makes their sum approximately zero. This algebraic property does not show that their errors are independent or normally distributed. Those require design knowledge and diagnostics.

The nitrogen coefficient now describes a change while rainfall is held fixed in the model. It may differ from the simple-regression coefficient because the models ask different questions. Omitted confounders, measurement error, and nonlinearity can still bias interpretation. Adding predictors raises ordinary \(R^2\) even if they contribute little; high \(R^2\) does not establish causality or reliable future prediction.

Strongly correlated predictors make separate coefficients unstable. In the crop trial, treatment and applied nitrogen are closely linked, so including both without thought can make individual effects hard to interpret. Select predictors using scientific reasoning, design, and an evaluation plan rather than repeated p-value searches.

14.6 Residuals, leverage, and influence

old <- par(mfrow = c(2, 2))
plot(multiple)
par(old)

        52         81         74         10         94          3 
0.07415445 0.06520610 0.04821445 0.04345712 0.03896112 0.03604932

The residual-versus-fitted plot checks mean structure, the Q–Q plot checks the error distribution, the scale-location plot checks spread, and leverage/influence diagnostics identify observations that can strongly affect estimates. Check influential records against source information; do not delete them merely to improve fit. Classical t-tests and intervals need assumptions about errors, including independence and constant variance. Normality concerns the errors for small-sample inference, not every predictor’s marginal distribution.

14.7 Categorical predictors and reference levels

Regression can include categorical variables through indicator coding. A two-variety example illustrates this without requiring the varieties to be interpreted as numeric doses. The reference level determines the intercept’s meaning, while the fitted mean for each observation remains unchanged under a consistent recoding.

trial <- read.csv("data/crop_trial.csv")
trial$variety <- factor(trial$variety, levels = c("A", "B"))
trial$block <- factor(trial$block)
variety_model <- lm(yield_t_ha ~ block + treatment + variety, data = trial)
coef(variety_model)
     (Intercept)           block2           block3           block4 
       3.4150000        0.1941667        0.3391667        0.5725000 
          block5 treatmentControl treatmentMineral         varietyB 
       0.4166667       -0.7125000        0.5190000        0.2340000

The varietyB coefficient compares B with A conditional on the other terms in this additive model. It assumes a common variety difference across treatments. The preceding ANOVA chapter explains how a treatment-by-variety interaction relaxes that assumption. ANOVA and regression are connected expressions of linear modelling, rather than unrelated procedures selected solely by the appearance of a response column.

14.8 Residual standard error and explained variation

The residual sum of squares measures unexplained squared deviations after fitting. Dividing by residual degrees of freedom and taking a square root gives the residual standard error, in yield units. \(R^2\) compares residual sum of squares with the total sum of squares around the observed mean:

\[R^2=1-\frac{\sum(y_i-\widehat{y}_i)^2}{\sum(y_i-\bar{y})^2}.\]

rss <- sum(residuals(multiple)^2)
tss <- sum((farm$yield_t_ha - mean(farm$yield_t_ha))^2)
c(manual_R_squared = 1 - rss / tss,
  reported_R_squared = summary(multiple)$r.squared,
  residual_standard_error = sqrt(rss / df.residual(multiple)))
       manual_R_squared      reported_R_squared residual_standard_error 
              0.6888415               0.6888415               0.3469405

An in-sample \(R^2\) describes fit to the observed response variation under that model. It is not the percentage probability that a prediction is correct. A narrow predictor range can produce a low \(R^2\) even when a small slope is estimated usefully; a common time trend can produce a high \(R^2\) for an unsuitable causal interpretation. Compare models in relation to their purpose and predictor domain.

14.9 Nonlinearity and an apparent fertilizer optimum

Crop response to a nutrient may increase initially and then approach a plateau or decline. A straight line over a restricted range can approximate part of that response without defining a biological optimum. A quadratic model adds a squared predictor term. In R formulas, write I(x^2) so the power is interpreted arithmetically.

quadratic <- lm(yield_t_ha ~ nitrogen_kg_ha + I(nitrogen_kg_ha^2) + rainfall_mm,
                 data = farm)
summary(quadratic)

For a concave quadratic \(a+bN+cN^2\) with \(c<0\), its mathematical maximum occurs at \(-b/(2c)\). If c is positive, the stationary point is a minimum, not an optimum. Even a concave fitted curve may place its maximum outside the observed nitrogen range, where it is unsupported extrapolation. The supplied simulation is generated with a linear mean response, so a quadratic term should not be presented as discovering a true fertilizer optimum.

An economic optimum additionally depends on crop price, input cost, and an appropriate response function. A fitted yield curve alone cannot supply those missing quantities. A defensible recommendation also needs replicated evidence across relevant environments and an assessment of uncertainty. In this introductory course, use nonlinear patterns to motivate questions and model checks before offering recommendations.

14.10 Predict and evaluate honestly

new_farm <- data.frame(nitrogen_kg_ha = 80, rainfall_mm = 650)
predict(multiple, new_farm, interval = "confidence")
       fit      lwr      upr
1 4.544382 4.474566 4.614198
predict(multiple, new_farm, interval = "prediction")
       fit      lwr      upr
1 4.544382 3.852271 5.236493
set.seed(531)
train_id <- sample(seq_len(nrow(farm)), size = 75)
train <- farm[train_id, ]
test <- farm[-train_id, ]
fit_train <- lm(yield_t_ha ~ nitrogen_kg_ha + rainfall_mm, data = train)
pred <- predict(fit_train, test)
baseline <- rep(mean(train$yield_t_ha), nrow(test))
data.frame(method = c("Regression", "Training mean"),
           RMSE = c(sqrt(mean((test$yield_t_ha - pred)^2)),
                    sqrt(mean((test$yield_t_ha - baseline)^2))),
           MAE = c(mean(abs(test$yield_t_ha - pred)),
                   mean(abs(test$yield_t_ha - baseline))))
         method      RMSE       MAE
1    Regression 0.3892038 0.3225455
2 Training mean 0.6895416 0.5703840

A confidence interval concerns the mean response at the specified predictors; a prediction interval includes variation in a new observation and is wider. Both rely on the model. Avoid extrapolation outside the training range and consider combinations of predictors that may be unusual even when each is individually within range.

A random holdout is suitable for these independent simulated records. For repeated farms, spatial clusters, or time series, split by group, location, or time as appropriate. Fit preprocessing steps using training data only. One split gives an unstable estimate, so cross-validation may be needed for serious model comparison. The test set should not become another training set through repeated tuning.

14.11 Practical 15 and exercises

  1. Compare Pearson and Spearman coefficients and explain their target relationships.
  2. Interpret the rainfall coefficient and its units. Why is it not automatically a causal rainfall effect?
  3. Compare simple and multiple nitrogen slopes. Explain what changes in their interpretation.
  4. Compare a confidence and prediction interval for the same new record.
  5. Evaluate the held-out model against the training-mean baseline. Identify a realistic setting where a random row split would be inappropriate.

Chapter review. Correlation describes association; regression specifies a conditional response; prediction requires separate evaluation. Design and domain knowledge remain necessary for causal interpretation.

14.12 Live R laboratory

Fit and interpret a yield model

Edit the code, then select Run R. The first run downloads R into your browser and may take a little time. Copy code also lets you use this example in RStudio.

trial <- data.frame(nitrogen = c(0, 20, 40, 60, 80, 100),
                    yield = c(2.0, 2.6, 3.0, 3.7, 3.9, 4.5))
model <- lm(yield ~ nitrogen, data = trial)
summary(model)
predict(model, newdata = data.frame(nitrogen = 50), interval = "prediction")
plot(yield ~ nitrogen, trial, pch = 19, col = "#237f83",
     xlab = "Nitrogen (kg/ha)", ylab = "Simulated yield (t/ha)")
abline(model, col = "#bc7c21", lwd = 2)

Investigate. Interpret the slope with units and distinguish a prediction interval for a new observation from a confidence interval for the mean. Do not extrapolate this simulated linear response to arbitrary doses.
