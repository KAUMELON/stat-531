# Interactive teaching edition · 16 October 2026

The full restored chapters remain in place. The reading design follows the author's companion agricultural-statistics textbook: Georgia/serif explanations, navy headings, gold active navigation, coloured pedagogical boxes, framed worked calculations, shaded R code, and copy controls.

Installation screenshots are authentic captures of CRAN and Posit's official download pages on 16 October 2026. The guide records R 4.6.1 and RStudio Desktop 2026.10.0 build 233 as offered on that date. Installer dialogue images from the old release remain archived; they are no longer used to illustrate current installation. The original pane illustration is explicitly labelled historical. The build still uses the existing local R 4.5.2; no software on the user's computer was upgraded.

Sources: https://cran.r-project.org/bin/windows/base/ and https://docs.posit.co/ide/user/download.html. Design reference: https://www.agrinoteskau.com/agstat-textbook.html, which embeds https://statoberrypapaya.github.io/TextbookofAgstat/.

Each of the 14 teaching chapters contains a self-contained Live R laboratory. Students can edit, execute, reset, and copy its code. Text and graphics are generated by real R through webR 0.6.0, loaded only after Run is selected. The pinned distribution is https://webr.r-wasm.org/v0.6.0/webr.mjs; the PostMessage communication mode supports ordinary static hosting without special isolation headers. API reference: https://docs.r-wasm.org/webr/v0.6.0/plotting.html.

These labs use base R and embedded data or R's built-in datasets. All ordinary book chunks remain copyable for RStudio, including package-based analyses and report-rendering examples. Browser labs require a network connection on first load; execution persists in that page's session. Reset restores text, not the entire R session. Reload the page for a fresh session. In-browser report compilation, desktop dialogs, and arbitrary installed desktop packages are not provided.

Validation: full 20-document HTML build completed, all internal link/anchor/image checks passed, and all 14 live exercise scripts passed in separate fresh R processes with warnings treated as errors. Browser verification covers calculation, editing, resetting, copying, errors, regression output, and graphics. This is representative functionality and visual testing, not exhaustive browser/accessibility certification.
