19  Large-sample tests

Learning outcomes

State hypotheses and interpret p-values, and carry out large-sample Z tests for a mean, two means, a proportion, two proportions and two standard deviations.

19.1 Testing of hypotheses: a quick review

A statistical hypothesis is a statement about a population parameter. A test of hypothesis decides, using sample data, whether the data are consistent with the null hypothesis \(H_0\) (usually “no difference” or “no effect”) or provide evidence for the alternative hypothesis \(H_1\).

The general procedure is:

  1. State \(H_0\) and \(H_1\). The alternative may be two-sided (\(\mu \ne \mu_0\)) or one-sided (\(\mu > \mu_0\) or \(\mu < \mu_0\)).
  2. Choose the level of significance \(\alpha\), usually 0.05 or 0.01.
  3. Compute the test statistic from the sample.
  4. Find the p-value: the probability, if \(H_0\) were true, of a test statistic at least as extreme as the one observed. Equivalently, compare the test statistic with the critical value.
  5. Decision: reject \(H_0\) if \(p \le \alpha\) (or if the statistic falls in the critical region); otherwise do not reject \(H_0\).
\(H_0\) true \(H_0\) false
Reject \(H_0\) Type I error (probability \(\alpha\)) Correct decision (power \(1 - \beta\))
Do not reject \(H_0\) Correct decision Type II error (probability \(\beta\))
Note

“Do not reject \(H_0\)” is not the same as “\(H_0\) is true”. It only means that the data do not provide enough evidence against it. Always report the p-value (and, where possible, a confidence interval) rather than only “significant” or “not significant”.

19.2 Large-sample (Z) tests

When the sample size is large (as a rule of thumb \(n \ge 30\)), the central limit theorem ensures that the sample mean, the sample proportion and many other statistics are approximately normally distributed, whatever the distribution of the population. A test statistic of the form

\[Z = \frac{\text{statistic} - \text{hypothesised value}}{\text{standard error of the statistic}}\]

then follows approximately the standard normal distribution \(N(0, 1)\) under \(H_0\). Critical values of \(Z\):

Level of significance Two-sided test One-sided test
5% 1.96 1.645
1% 2.576 2.326 
qnorm(c(0.975, 0.995))   # two-sided critical values at 5% and 1%
[1] 1.960 2.576
qnorm(c(0.95, 0.99))     # one-sided critical values at 5% and 1%
[1] 1.645 2.326

Base R has no function for the Z test of means, but it takes only a few lines. The following helper function computes the p-value for a given \(Z\):

z_pvalue <- function(z, alternative = c("two.sided", "less", "greater")) {
  alternative <- match.arg(alternative)
  switch(alternative,
    two.sided = 2 * pnorm(-abs(z)),
    less      = pnorm(z),
    greater   = pnorm(z, lower.tail = FALSE))
}

19.3 Test for a single mean

To test \(H_0: \mu = \mu_0\),

\[Z = \frac{\bar x - \mu_0}{\sigma / \sqrt{n}}\]

When the population standard deviation \(\sigma\) is unknown, it is replaced by the sample SD \(s\), which is acceptable for large \(n\).

Example 19.1 Is the mean potato yield at La Molina (LM-02) different from 30 t/ha?

\(H_0: \mu = 30\) against \(H_1: \mu \ne 30\).

Solution

mu0 <- 30
n <- length(lm02)
z <- (mean(lm02) - mu0) / (sd(lm02) / sqrt(n))
z
[1] 5.086
z_pvalue(z)
[1] 0.000000366

\(|Z| =\) 5.09 > 1.96 and \(p < 0.001\), so we reject \(H_0\): the mean yield at LM-02 differs significantly from 30 t/ha (it is higher). A 95% confidence interval for the mean is

mean(lm02) + c(-1, 1) * qnorm(0.975) * sd(lm02) / sqrt(n)
[1] 32.85 36.43

19.4 Test for the difference of two means

To test \(H_0: \mu_1 = \mu_2\) with two large independent samples,

\[Z = \frac{\bar x_1 - \bar x_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}\]

Example 19.2 Do mean yields at LM-02 and Ayacucho differ?

Solution

n1 <- length(lm02); n2 <- length(ayac)
se <- sqrt(var(lm02) / n1 + var(ayac) / n2)
z  <- (mean(lm02) - mean(ayac)) / se
z
[1] 9.162
z_pvalue(z)
[1] 5.087e-20

\(Z =\) 9.16, \(p < 0.001\): the mean yield at LM-02 is significantly higher than at Ayacucho.

19.5 Test for a single proportion

If \(X\) successes are observed in \(n\) trials, the sample proportion is \(\hat p = X/n\). To test \(H_0: P = P_0\),

\[Z = \frac{\hat p - P_0}{\sqrt{P_0 (1 - P_0) / n}}\]

Example 19.3 A seed company claims that the germination of its seed is 90%. In a test of 500 seeds, 430 germinated. Is the germination lower than claimed?

\(H_0: P = 0.90\) against \(H_1: P < 0.90\) (one-sided).

Solution

x <- 430; n <- 500; P0 <- 0.90
p_hat <- x / n
z <- (p_hat - P0) / sqrt(P0 * (1 - P0) / n)
z
[1] -2.981
z_pvalue(z, "less")
[1] 0.001435

\(Z =\) -2.98 < −1.645 and \(p =\) 0.0014, so we reject \(H_0\): the germination is significantly lower than 90%.

The built-in prop.test() gives the same p-value; it reports \(\chi^2 = Z^2\) instead of \(Z\):

prop.test(x = 430, n = 500, p = 0.90, alternative = "less", correct = FALSE)

    1-sample proportions test without continuity correction

data:  430 out of 500, null probability 0.9
X-squared = 8.9, df = 1, p-value = 0.001
alternative hypothesis: true p is less than 0.9
95 percent confidence interval:
 0.0000 0.8836
sample estimates:
   p 
0.86
Tip

prop.test() applies Yates’ continuity correction by default (correct = TRUE), which gives a slightly larger p-value. For small samples use the exact binomial test, binom.test(430, 500, p = 0.9).

19.6 Test for the difference of two proportions

To test \(H_0: P_1 = P_2\),

\[Z = \frac{\hat p_1 - \hat p_2}{\sqrt{\hat p (1 - \hat p)\left(\dfrac{1}{n_1} + \dfrac{1}{n_2}\right)}}, \qquad \hat p = \frac{x_1 + x_2}{n_1 + n_2}\]

where \(\hat p\) is the pooled proportion.

Example 19.4 In a field trial, 36 of 200 plants sprayed with a fungicide and 58 of 200 unsprayed plants showed leaf blight. Does the fungicide reduce disease incidence?

Solution

x1 <- 36; n1 <- 200     # sprayed
x2 <- 58; n2 <- 200     # unsprayed
p1 <- x1 / n1; p2 <- x2 / n2
p  <- (x1 + x2) / (n1 + n2)
z  <- (p1 - p2) / sqrt(p * (1 - p) * (1 / n1 + 1 / n2))
c(p1 = p1, p2 = p2, z = z)
    p1     p2      z 
 0.180  0.290 -2.594 
z_pvalue(z, "less")
[1] 0.004739
# The same with prop.test (two-sided by default)
prop.test(c(x1, x2), c(n1, n2), alternative = "less", correct = FALSE)

    2-sample test for equality of proportions without continuity correction

data:  c(x1, x2) out of c(n1, n2)
X-squared = 6.7, df = 1, p-value = 0.005
alternative hypothesis: less
95 percent confidence interval:
 -1.00000 -0.04085
sample estimates:
prop 1 prop 2 
  0.18   0.29

Disease incidence was 18% with the fungicide and 29% without. \(Z =\) -2.59 and the one-sided \(p =\) 0.0047 < 0.05, so the fungicide significantly reduced the incidence of leaf blight.

19.7 Test for the difference of two standard deviations

For large samples the standard error of \(s\) is approximately \(\sigma/\sqrt{2n}\), so to test \(H_0: \sigma_1 = \sigma_2\),

\[Z = \frac{s_1 - s_2}{\sqrt{\dfrac{s_1^2}{2n_1} + \dfrac{s_2^2}{2n_2}}}\]

s1 <- sd(lm02); s2 <- sd(ayac)
z <- (s1 - s2) / sqrt(s1^2 / (2 * n1) + s2^2 / (2 * n2))
c(s1 = s1, s2 = s2, z = z)
   s1    s2     z 
8.370 7.053 2.406 
z_pvalue(z)
[1] 0.01614

\(|Z| < 1.96\), so the variability of yield does not differ significantly between the two environments.

19.8 Live R laboratory

Z test for two proportions

Edit the code, then select Run R. The first run downloads R into your browser and may take a little time. Copy code lets you use the example in RStudio.

# Leaf blight: 36 of 200 sprayed plants, 58 of 200 unsprayed plants
x1 <- 36; n1 <- 200; x2 <- 58; n2 <- 200
p1 <- x1 / n1; p2 <- x2 / n2; p <- (x1 + x2) / (n1 + n2)
z <- (p1 - p2) / sqrt(p * (1 - p) * (1 / n1 + 1 / n2))
c(p1 = p1, p2 = p2, z = z, one_sided_p = pnorm(z))

prop.test(c(x1, x2), c(n1, n2), alternative = "less", correct = FALSE)

Investigate. Halve both sample sizes (18 of 100 and 29 of 100). Does the fungicide effect remain significant? What does this tell you about sample size?

Historical Insights

Abraham de Moivre derived the normal approximation to the binomial in 1733, and Pierre-Simon Laplace extended it into the central limit theorem in 1810. This theorem is why large-sample tests work for almost any population.

Important formulae

Z for a single mean:

\[ Z = \frac{\bar x - \mu_0}{s/\sqrt n} \tag{19.1}\]

Z for two means:

\[ Z = \frac{\bar x_1 - \bar x_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}} \tag{19.2}\]

Z for a proportion:

\[ Z = \frac{\hat p - P_0}{\sqrt{P_0(1-P_0)/n}} \tag{19.3}\]

Z for two proportions:

\[ Z = \frac{\hat p_1 - \hat p_2}{\sqrt{\hat p(1-\hat p)(1/n_1 + 1/n_2)}} \tag{19.4}\]

Quick revision

  • Large \(n\) → statistic ≈ normal → \(Z\) test.
  • Two-sided: |Z| > 1.96 (5%), 2.576 (1%); one-sided: 1.645, 2.326.
  • Proportion → prop.test(); small samples → binom.test().
  • Report the estimate and confidence interval, not only the decision.
  • Not rejecting \(H_0\) ≠ proving \(H_0\).
